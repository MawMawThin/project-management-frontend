# Project Management Frontend

React + Vite + TypeScript UI for Project Management.

## Run

```powershell
cd C:\Users\PC\Desktop\Project_Management\project-management-frontend
npm install
npm run dev
```

Open http://localhost:5173  

Backend must be running on http://localhost:8080

## Structure

```
src/
  api/                 # HTTP client → Spring Boot
  components/
    layout/
    ui/
  features/
    dashboard/page/
    schedule/page/
    bugs/page/
    structure/page/
    meetings/page/
  utils/
```
